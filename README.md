# YCurrencies
Plugin to create unlimited number of custom currencies for your server. Made and tested on version **1.19.4**, but should also work on higher versions.
Plugin requires at least [Paper](https://github.com/PaperMC/Paper), won't work on Spigot or Bukkit.

# Features
### Currencies:
- With configurable name
- messages
- commands

### Modules:
Three configurable modules that give currency:
- on interval, every x seconds
- when killing a mob
- when mining a block

### Other:
- Support for [PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI)
- Support for [MiniMessage](https://docs.advntr.dev/minimessage/index.html)
- PAPI placeholders to use in other plugins [(Click)](https://github.com/Ynfuien/YCurrencies/wiki/Placeholders)
- Fully customizable translations with lang files
- Commands with tab completions
- Data saved in MySQL database
- API for developers

# Getting started
Download plugin from a [releases](https://github.com/Ynfuien/YCurrencies/releases) page and put it in plugins folder. Start server, don't worry about plugin not working, configure database connection in `config.yml`, and restart server. **Plugin won't work without a database.** After restart plugin should work without any problems, and now you can configure all generated files, according to your liking. You can learn more on [wiki](https://github.com/Ynfuien/YCurrencies/wiki) page.
